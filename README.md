## 🚀 Tech Stack

- **Framework:** React 18
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Deployment:** GitHub Pages
- **Build Tool:** Vite

## 🏗️ Local Development
```bash
# Clone the repository
git clone https://github.com/harshakshit/harshakshit.github.io.git

# Navigate to directory
cd harshakshit.github.io

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
